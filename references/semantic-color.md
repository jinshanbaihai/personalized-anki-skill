# 让配色减少阅读负担

选择同色、异色、背景分组、加粗或局部高亮，都要服务当前材料。没有必须填写的色表、固定色数、每个特征专属一种颜色或全球固定色义。AI 可自主判断；同色最清楚时无需增加颜色。不同概念也可能共享一种强调色，只要读者不会因此误解它们相同。

学科概念使用 English，即使是 price 这样的常见词；普通连接与解释用中文，语境判断见 terminology.md。强调要形成重点，不能机械给所有英文、符号和单位各染一种色。必要时以邻近标签解释颜色；不必每张卡添加图例和说明面板。

默认阅读习惯是左到右或上到下，不是禁用其他布局。分类中心分支、反馈循环环形等可以自然使用；检查实际材料中的起点、方向、关系是否清楚。

参考 W3C：不能仅靠颜色表达必要意义；文字通常与背景至少 4.5:1、大字至少 3:1。此为可访问性检查，不是干眼症疗效保证。来源：https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html 与 https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html 。

自检问题：不用某个颜色或分类规则是否更好读？如果是，删掉规则。不要为了展示设计工作量而添加视觉编码。
