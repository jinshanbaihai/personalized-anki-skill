# 讲清概念的制作判断

下面是作者思考的方向，不是每张卡必须填满的表，也不交给用户填写。

- 读者现在认识哪些对象，哪些术语或前提需要补齐？
- 本卡要讲清的概念、关系或图是什么？一个完整目标可以包含多项相互依赖的知识，不等于一个孤立词。
- 条件、原因、结论、边界和例子如何连起来？把长解释继续细分成有意义的分支。
- 图具体解释哪一层关系，文字还需要补什么？涉及变化时，用前后对照或有意义的交互把变化画清楚。
- 母件知识与易错点是否覆盖？已有卡片是否重复？来源支持哪些内容，哪些解释由作者补充？

例如 precision／accuracy 的核心是两个比较对象：先解释重复读数与 true value，再展示分散和偏移为何是不同判断，最后用例子串起来。moment 的核心可能是确定 perpendicular distance：pivot、line of action 与垂线需要一起理解，不应仅为“原子化”拆得彼此失去参照。这些不是固定图形或固定段数模板。

默认只有一个阅读面：场景、必要条件、完整导图和讲解首次出现就可见。无需猜答或翻面；Space 听讲，Enter 继续，1 次日再看。只有用户另行要求测验时才制作独立测验，不把四选一或答题关卡作为阅读卡必需部分。

## 常见失败及修正方向

- 只写“accuracy：接近 true value”：补上比较双方、基准和一个能理解的例子。
- 只写“所以 a 向上”：解释 velocity 如何改变、正方向和前后状态。
- 只写“图上显然”：明确观察对象与关系，用图实际展示。
- 为少字删掉条件，或为多字反复总结：检查每段是否提供必要对象、原因、条件或例子。
- 为一页容纳强行缩成小字：先调整关系组织、重复内容与空间分配。核心因果保持一页可见；放大用于细看，不是补全被藏起来的解释。
- 每张重放同一篇基础章节：复用已经覆盖的内容，当前卡保留足以独立读懂的必要前提。

验收用实际内容与窗口：关系完整、初学者能跟上、图准确、听讲顺序正确、操作可用。无滚动或技术检查通过都不能单独证明用户已经理解。
