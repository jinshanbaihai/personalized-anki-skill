## 方法题的给分模式

**Find the sampling distribution（6–7 分）**：M1/B1 全部取值且无多余 → B1 单个体概率 → M1 × 3（逐个概率；独立抽样用 p^k、k·p^{k−1}q、nCr；不放回用递减分母）→ A1 全表（“Need not be in a table but probabilities must be attached to the correct total”）。不放回题按放回算：SC 封顶（Jun 2024 Q4(b) 最多 M1B1M1M1M0A0）。

**Show that 给定概率（1 分）**：B1cso，写出完整乘式（10/50 × 9/49 = 9/245）。含方程的 show that：A1*，方程列对后至少再写一行。

**List（1–2 分）**：无多余；与顺序有关的统计量列有序结果（Jan 2025 不接受 ×2 简写）；与顺序无关时可写 ×3（Oct 2025 condone permutations，SAM 接受 3 × (…)）。

**反求总体概率（Hence）**：M1 方程（p³ = …）→ A1 p、q → M1 各概率（须见代入）→ A1。

**最小 n（3 分）**：M1 正确不等式（允许 = 或反向）→ M1 n > 临界值、对数式或相邻两次试算 → A1 整数 n，cao，不写不等式。已出现：P(T = 0) < 0.15 → 51（Jun 2024）；P(Y ⩾ 1) > 0.95 → 18（Jan 2024）、16（Jun 2025）；P(Y = 0) < 0.2（Oct 2020，题干）。

## 典型失分（ER 与 MS 合并）

1. sampling frame 漏 “all”；写成部分名单或非个体的清单。
2. sampling unit 写成个体的属性（opinions、systems）或数量（number of shops）。
3. 优缺点只写 “more uncertain”；census 与 sample 写反。
4. census 可行题去复述定义或比较优缺点，没写“总体的特征”。
5. 会背 statistic 定义却选错（把清单 A 当 statistic）；理由写 “because it is known”；只判断不写理由。
6. 不放回题按放回算（SC 封顶）；第二次抽取的分子分母没同时减 1。
7. 排列数漏乘（4C2 = 6 写成 4；3p²q 漏 3）；odd/even 概率对调。
8. 统计量算错类型：mode 求成 median、median 求成 total、range 漏 R = 0。
9. 列举题画树状图、列错对象、有多余项；概率和不为 1 却不检查。
10. 最小 n：1 − P(Y ⩽ 1) 代替 1 − P(Y = 0)；除以负对数不变号得到 n − 1；终点写成 n ⩾ 51。
11. 非精确值不给三位有效数字；show that 少写中间行。
