# 初学者体验检查

这份清单来自实际用户反馈后的重做。它帮助作者找问题，不代替用户的理解检验。

## 从哪里开始检查

先看场景与任务。读者是否知道谁在运动、测量或相互作用，已知什么，要判断什么？默认用户可以第一次接触这个知识点。只有标题、公式、术语和装饰图时继续补齐。

再看图与解释。每个箭头、颜色、坐标轴和符号有没有可查的含义？指代“这里”“这部分”是否能定位？解释中的变化有没有出现在图中？数值例子与图的比例是否相符？分段后同一对象是否保持可追踪？

最后看操作。能否直接进入讲解？当前目标的完整关系是否在一页看全，而非靠逐段点击拼接？唯一播放器能否暂停、继续、重播，Space、Enter 与 1是否顺手？解释与图是否同屏？必要术语是否藏得太深？字体应按实际显示后的大小检查，不能只看 SVG 原始字号。

## 研究依据与边界

[Nielsen Norman Group](https://www.nngroup.com/articles/ten-usability-heuristics/)：熟悉的语言、可见状态和明确反馈。用于减少理解界面的额外工作。

[Mayer 的分段、预训练与模态原则](https://doi.org/10.1017/CBO9780511816819.012)：先认识关键对象、按学习者节奏分段。实验结论支持方向，不规定每张卡固定字数或固定页数。

[SuperMemo 制卡实践建议](https://www.supermemo.com/en/blog/twenty-rules-of-formulating-knowledge)：先理解、再记忆，使用清楚的知识表述。属于实践指导，不把它写成医学或随机对照实验结论。

## 交付的两类证据

内容证据：作者核对的来源、学习目标、图文对应与小例子。

操作证据：实际 Anki 的可见卡片、按钮、音频、导入更新与学习记录保持。

用户能否理解仍需要实际反馈。发生“看不懂”时回到具体卡片寻找缺失的对象、含义和推理，避免再次只修颜色、字号或按钮。

术语检查同时覆盖标题、根节点、主干、图标签和音频稿。不要只检查显眼长词，price、quantity 等在学科语境中同样使用 English；首次含义和缩写是否对初学者清楚？见 terminology.md。
