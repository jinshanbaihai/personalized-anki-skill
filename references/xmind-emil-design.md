# 让局部知识图轻松可读

母图组织一个主题的全貌，卡片展示其中可独立理解的局部。用紧凑层级、明确连线和稳定阅读方向帮助读者找到关系。通常左到右或上到下；分类、循环或交叉关系有需要时采用合适结构。正文用自然短句，节点可以直接容纳解释、完整学科图、表格或数学。

从真实 Anki 可用区域和舒适字号开始排版。保持主干突出、分组清楚、间距一致；对齐和字重通常比更多边框、色彩更有效。必要的原因和对照同时可见，当前范围过大就重分知识单位。整章母图不通过缩字充当复习卡。

颜色用于追踪对象、分组或显示有意义的差异。图中坐标、比例关系、符号与曲线不能为了排列好看而失真。文字解释靠近相关证据；关系只藏在 tooltip 中时，把必要含义写到节点或图旁。

涉及版式设计时，实际读取可用的 `anthropic-skills:emilkowalski-skills` 及其 apple-design／emil-design-eng 指引；整批复用。应用 typography、simplicity、即时反馈和 reduced-motion 的原则，按钮状态清楚，键盘快刷即时响应。交互动画按需要使用，知识阅读本身保持稳定；默认样式的科学依据和用户体验分别审查。

目标环境没有该 skill 时，使用此处摘要与[原作者资源](https://github.com/emilkowalski/skills)继续，并说明实际采用的依据。既有样例只是工程能力示范，按当前材料自主选择表达。检查实际窗口、截图、字号和操作；发现阅读困难就调整内容或版式。
