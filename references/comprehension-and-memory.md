# 先教明白，再帮助记住

研究核对日期：2026-09-24。本文件服务单面思维导图阅读卡的制作与验收，不要求用户变更操作习惯。

## Flashcard 与当前产物的区别

传统 flashcard 通常给出提示，学习者尝试提取答案，再核对反馈。有效性不能只归给卡片外形或文字简短。Roediger 与 Karpicke（2006）的 prose 学习实验发现，延迟测试中，先前的 retrieval practice 比等量 restudy 更有利；短时表现与自信不能代表延迟记忆。当前用户明确选择直接阅读的单面卡，应称为支持理解与间隔回顾的阅读卡；可以自发 recall，但不能宣称浏览、点 Good 就取得同样的 retrieval 收益，也不借研究强制恢复问答界面。[论文及作者摘要](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/)

## 怎样才算讲明白

Kintsch（1994）区分复述文本与用文本知识进行推断、解决问题。低背景知识读者需要明确、连贯的文本；只记住句子可能仍不理解句子间为何有因果关系。文章也讨论有基础的读者可能从主动填补某些缺口中受益，所以不能据此宣布所有文本越长越好。本用户反复反馈缺少前提、解释跳步，应选择显性补足，不把作者知道的背景留给读者猜。[原文](https://andymatuschak.org/files/papers/Kintsch%20-%201994%20-%20Text%20comprehension,%20memory,%20and%20learning.pdf)

由此形成的制作判断：先给对象与必要前提，再连接动作、比较、机制与结论。中文主语、指代、限定和比较基准的检查，是针对本用户语言障碍的工程应用，不是该论文直接测试过的中文句法配方。前置定语缺失会丢条件；前置定语过长也可能掩盖中心对象。按意思补足与拆解，不制定每句字数或强制重复主语的规则。

Rawson、Thomas 与 Jacoby（2015）在三项实验中比较 illustrative examples 与继续学习定义。在后续新例子的概念分类任务上，学习例子的条件表现更好，但效果受例子安排与定义是否同时呈现影响。这支持具体例子与概念对应，不证明只讲故事即可掌握整门学科或作文。[作者提供的原文，pp. 483–504](https://www.larryjacoby.ca/images/Rawson2015.pdf)

IES 实践指南把 abstract 与 concrete 表达的连接，以及 graphics 与 verbal descriptions 的结合列为有研究支持的方向；不是叫制作者把图与文字并排放好就算完成。例子应能说明抽象关系，图形应让关系可观察，文字负责解释对应和理由。不要求所有卡都使用全部形式。[官方指南，recommendations 3、4、7](https://ies.ed.gov/ncee/WWC/Docs/PracticeGuide/20072004.pdf)

## “记忆点”的工作定义与方法选择

这里把“记忆点”理解为能帮助读者理解并再次找回概念的有意义线索，不把它冒充标准化心理学量表或保证记忆的理论。制作者考虑下列方向，也可以采用更适合材料的新方法：

- 抽象判断难以理解时，让读者看到具体的人、对象、行动与后果，再明确对应的一般原理。
- 两个概念容易混淆时，在同一比较基准下呈现关键差异；必要时用反例说明边界，而非罗列两份定义。
- 只有结果、没有理由时，展开引起变化的机制，说明不变量和中间连接；箭头与“所以”不能代替解释。
- 科学关系适合图示时，研究成熟学科图法，保留真正承载关系的形状、位置、坐标和变化，配合具体讲解。
- 解释完整后，可用含义明确的主干句或提示语帮助找回整条关系；提示语本身不替代解释，也不变成额外背诵任务。

这些是可选择和组合的教学方向，不是固定五模块模板。必须处理实际存在的理解缺口，方法由材料决定；不能以“保留创造力”为理由省略必要教学，也不能以“严格执行”为理由叠加无用技巧。

Dunlosky 等（2013）对十种学习方法的综述给出不同证据与适用性评价；practice testing、distributed practice 的总体支持更广，elaborative interrogation、self-explanation 有条件与边界，keyword mnemonic 的普遍效用有限。不能把所有 mnemonic、加粗或高亮都称作必然有效。尤其不能把学习者自己生成解释的研究，直接当成“AI 多写几句就产生相同效果”的证明。当前用途是让卡片提供足以理解的材料，不是声称制作者能替用户完成记忆。[综述与全文入口](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html)

Harp 与 Mayer（1998）研究中，醒目却无关的 seductive details 会损害核心内容学习。采用案例要保留帮助理解的细节，避免让趣味情节夺走注意；这不构成删除必要解释的借口。[原始论文](https://www.researchgate.net/profile/Richard-Mayer-4/publication/232595492_How_Seductive_Details_Do_Their_Damage_A_Theory_of_Cognitive_Interest_in_Science_Learning/links/57799b8408ae4645d611f204/How-Seductive-Details-Do-Their-Damage-A-Theory-of-Cognitive-Interest-in-Science-Learning.pdf)

## 案例变式与合理误解

用户提出“每个子教学点考虑至少两个案例”的意图，是让抽象概念反复落回可理解的现实情境。本 skill 将其作为主动探索方向，不作为例子配额。第二例可以再次说明同一原理，也可以改变一个关键条件帮助辨别边界；明确两个情境的共同机制与差异，比机械换名更重要。上述例子研究不支持所有学科、所有分支恰好两例的统一最优数量。

Prinz、Golke 与 Wittwer（2021）在 92 名大学生参与的 covariance 学习实验中发现，refutation text 可帮助带有误解的学习者理解内容；该实验中 think sheet 另有 transfer 收益。这支持针对已辨识的误解给予正确解释，但不证明罗列越多错误越好，也不能将其直接推广成高中所有学科的效果保证。本任务采用解释与对照，不要求用户填写研究中使用的工作表。[原始研究与公开全文](https://link.springer.com/article/10.1007/s11251-021-09535-8)

制作应用：考虑读者的日常词义、已有生活经验与合理推断可能如何偏离学科含义；优先使用用户反馈与可靠材料确认障碍。讲明为何容易这样想、关键区别在哪里，以及正确机制怎样作用。能靠清楚的正向解释消除的问题，不额外造一道错误题。制作者应广泛检查，卡面只呈现有助当前理解的防误解内容，避免无依据的“常见错误”、牵强提醒和超纲限定。以上为结合证据与用户偏好的设计判断，不是论文逐项验证过的固定流程。

## 制作前与制作后的验收

制作前明确本卡的学习目标与读者需要的背景：哪些概念必须现场解释，哪些比较容易混淆，哪个“所以”最可能跳步，哪些点值得完整展开。概览的分支标题不是讲解已经完成的证据。

制作后只看真实卡面，不借助母件和作者知识补全。逐个重要分支检查：主语是谁；陌生概念是什么意思；必要条件是什么；为什么有这个结果；例子／图中哪一处说明了原理；当前任务如何使用它。能复述原句仍不够，要检查是否能据卡面解释一个具体情境或辨别一个相近概念。这是制作者检查内容的方法，不是要求用户逐项作答。

解释长短由理解需要决定。把压缩句展开为有意义的子分支，用完整自然句说明关键机制，保留整条因果同屏。确有独立目标时拆卡，每卡保留必要背景，不切断逻辑让用户跨随机卡拼接。

必须区分三种证据：自动检查证明文件与交互可运行；制作者审阅证明已查找并修补可预见缺口；用户反馈才能说明该读者的实际体验。读者说看不懂，就定位术语、指代、前提、因果或表达的具体缺口，重新解释并返工，不能归咎于读者。首要目标是读懂，记忆效果次之；不能承诺任何读者一次阅读后永久记住。
