# Anki 实际验证与故障路径

## 分清制作测试与用户操作

构建成功、预览成功、临时集合导入成功，分别只确认一部分能力。结束前在用户实际使用的 Anki 客户端打开牌组，检查完整关系的可读性、图像、完整内容首次可见和整页播放，保存状态与窗口截图。检查报告写清客户端版本、可用窗口、测试过的状态和尚未测试的平台。

仅维护旧 teaching 卡时可按需使用附带的 `scripts/native_once.py`。它是 macOS 桌面 Anki 的临时插件模板，已在 26.08.1 桌面后端上验证。调用内部方法的部分与版本相关，迁移后核对对应源码或插件文档。普通导入能够完成时不需要安装插件。不要清除其他插件或历史来解决一个卡片模板问题。

## 常规路径

1. 确认本机 Anki 版本、当前资料目录和目标牌组。优先正常导入 apkg。
2. 记录导入前目标笔记及复习次数，导入时保留调度；重复导入只更新原有笔记。定位牌组时按名称查询，使用返回的本机 ID。
3. 打开实际卡片；检查单页完整关系、唯一播放器、Space 播放暂停、Enter 直接 Good、1 次日到期和媒体解析路径；安装及范围限制见 single-face.md，测试避免伪造用户学习记录。导入后未排到新卡时可以使用浏览器预览，不为了打开样张而清空学习记录。

## 界面工具卡住时

工具超时后先确认真实应用是否还在运行及其实际标识，换用应用 API 或临时插件。一个办法连续失败两次后改走其他可行路径，别重复同样的长等待。不要把后台已导入当作前台已经打开。

临时插件路径示例为用户 Anki 资料根目录下的 `addons21/codex_ccpt_once/`。目录中放置 `__init__.py`（本技能 `native_once.py` 的内容）、`meta.json` 和 `config.json`：

```json
{"name":"CCPT 一次性导入检查","disabled":false}
```

```json
{"package":"绝对路径/图像概念卡.apkg","deck":"目标牌组名称","output":"绝对路径/验证输出"}
```

确认 Anki 正常退出后再安装插件并重新打开；通过 `profile_did_open` 在应用自己的集合中导入，避免两个进程写同一集合。检查包路径来自当前工作产物。插件保留已有复习次数，按名称选中牌组，打开复习，保存旧卡两面截图，并短暂启动实际音频检验播放时间是否推进。它不替用户评分。成功后只移除自己的临时插件目录。

如果目标牌组当前没有待学卡，脚本打开 Anki 原生预览窗口，支持前后卡片与翻面，记录 `mode=native-preview`。这种方式保留调度，报告中说明处于预览。中途失败时保存错误、修复后重试；完成后确认临时插件已清理。

## 显示与媒体检查

- 使用实际 WebView 的 `innerWidth/innerHeight`。桌面菜单和评分按钮会占据窗口；单独预览的宽高通常不能代表实际阅读空间。
- 查看每幅图的全部文字边界、图形和朗读入口；检查正面是否带答案字段或正确理由，查看前后选择状态。
- 音频清单应全部存在、能够解码，成品速度为 1.75 倍。实际客户端检查 `document.baseURI` 与媒体 URL，观察播放 Promise 成功、时长有效、播放时间推进。仅通过对象模拟时不要称为实际播放成功。
- 浏览器的自动播放限制、用户音量、耳机路由和主观声音体验需要区分。播放时间推进说明播放器启动，不能替代用户对音色、重复数字与舒适度的反馈。
- 新 Anki 版本可能改变应用标识或内置 Python 路径；查询当前安装包，使用匹配版本的后端。外部后端只在集合关闭时访问。
- 使用 Qt 离屏 WebEngine 做制作测试时，创建有名称的 QApplication；若截图空白，检查 GPU 初始化，可用软件渲染。离屏截图仍不代替实际应用窗口。

## 启动页面切换

导入后若 collection 和 reviewer 已有 card，但 WebView 仍显示 deckbrowser，先检查启动阶段的异步页面加载。等主窗口完成初始化，再进入目标牌组 overview，随后进入 review 并检查实际 DOM。不要把启动时序问题解释成每日新卡额度不足。当前脚本在 26.08.1 上用分阶段进入页面的方式验证了正常复习与实际音频。

## 实际窗口与异步音频

制作预览的 1100×720 不能替代用户机器的实际 WebView。本次真实桌面可用阅读区域曾只有 1024×427；需要按实际尺寸检查图与解释的关系，以及主要按钮始终可到达。窗口高度较小时优先并排布局、减少重复标题和固定操作区，不通过把整张图缩到难读来追求零滚动。核心解释与完整因果保持同页，附加出处可以独立查看；不把核心讲解藏到下一屏。

播放前等待媒体实际开始，不在固定 1.4 秒后就把“没有播放进度”当成缺失音频。快速切换、暂停可能使旧的 play Promise 返回 AbortError；清理旧音轨时避免它的失败回调停止新音轨。播放器只让当前音轨的真实错误触发错误界面。

## 完整教学卡的追加检查

自定义 data-audio 属性并不足以让 Anki 导入器识别媒体。把引用同时写入隐藏的 audio src 媒体索引，再检查实际导入后的文件是否存在并能播放。仅检查 apkg 内包含音频，或 Anki 已识别引用的 missing 列表为空，均不足以验证自定义播放器。

以下仅适用于保留选择题或 lab 的旧卡维护，不触发新卡测验制作：真实点击选项 C，观察已选择记号；确认前反馈隐藏，确认后出现所选理由和对应答案；返回图解链接能够进入正确段落。动态力臂在 0°、30°、90° 核对垂直性与距离，测量图核对平移保留间距、改变分散保留均值。

原生预览能够用于学习与检查，不会自动提交复习评分。报告明确预览或正常复习，不把预览中的下一张按钮描述成已完成一次评分。
