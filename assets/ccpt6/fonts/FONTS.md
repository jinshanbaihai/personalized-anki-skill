# Bundled fonts

All files are subsets of fonts released under the SIL Open Font License 1.1 (https://openfontlicense.org).
They are Modified Versions: subset to the characters a card needs (CJK: GB2312 plus extras; Latin: Latin
range; math: full cmap with the MATH table) and renamed to `CCPT6 <role>` so that no Reserved Font Name
is used. Copyright (name ID 0) and the license notice (name IDs 13–14) are kept inside every file.
The builder copies them into the Anki collection with content-hashed `_` names.
